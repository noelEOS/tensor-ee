# Swin-T + UPerNet browser demo

The browser demo's documentation now covers both models in [DEMO.md](DEMO.md).
Start the Swin-T/UPerNet one-chip demo with:

```sh
PYTHONPATH=. python -m demos.browser.server --project YOUR_PROJECT --model swin-t
```

See [DEMO.md](DEMO.md#aoi-and-model-behaviour) for the one-chip grid and the three
Earth Engine stages, and [`docs/history/`](docs/history/README.md) for the archived
demo's verification records.
